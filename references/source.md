# 来源、许可证与证据边界

本 Skill 没有复制抖音页面代码或非公开接口实现。页面读取和报告生成逻辑按 Easy WebBridge 的公开业务接口实现；Easy WebBridge 仓库声明为 MIT。当前仓库自身使用 MIT License，完整文本见 `LICENSE`。第三方网页内容仍归各自权利人所有，报告只保存完成复核所需的最小可见文本摘录。

实际新增内容：

- 只选择一个在线 `browserId`，并为本次运行创建独立标签组。
- 只调用一次 `snapshot` 读取当前页面可见文本，不读取 Cookie、Local Storage、网络正文、账号凭证或非公开接口。
- 增加抖音 URL 校验、登录/验证码停止条件、可见指标换算和 Markdown/JSON 双格式报告。
- 仅接受 `/video/<作品ID>` 或 `/note/<作品ID>`，并用输入/快照作品 ID、页面标题或同作品交互节点建立有限提取边界；无法建立边界时失败，不读取固定的快照前若干行。
- 增加 `--mock` 与 `self-test`，让没有浏览器时也能验收解析和敏感字段清理。

这不是抖音官方 API，也不冒充官方 API，不代表官方评价或历史趋势。报告里的互动数字只记录采集时刻页面显示值；缩写换算不是官方精确历史数据。页面未显示的信息必须保持 `null`、空数组或明确限制，不能通过搜索摘要或模型猜测补齐。

指定 URL 的真实验收必须来自用户合法授权浏览器中的当前页面快照。`humanReview.enabled=true` 时由人工对照同一采集时点页面；`humanReview.enabled=false` 时，每个非空事实字段必须能由保留的最小快照或截图证据独立核对，证据不足的字段保持 `null`/空数组。Mock fixture 仅用于离线开发和失败路径测试，不能替代真实验收证据。

作者仅从目标作品区域内的明确作者标签或 `@作者` 文本提取，不使用全局用户链接兜底；页面“总结”“章节要点”等辅助摘要不属于原作品文案，也不能作为开头钩子证据。

SkillHub 的 `submitted` 状态只表示已提交/待审核；在平台审核通过且公开可见前，不得表述为已发布或公开可安装。
